> **Rise through the criminal underworld. Run jobs, build your Imperium, train skills, manage Heat, and scale into a kingpin.**  
> **Syndicate 102** is a browser-based **idle / empire management** game with **real-time timers** and **autosave**.

---

## 📌 Overview

**Syndicate 102** is a single-player browser idle game inspired by classic mafia progression systems:
- **Jobs** for **Money**, **Reputation**, and **Heat**
- **Imperium** upgrades that compound long-term growth
- **Training** that shapes your build (economy, combat, stealth, intelligence, etc.)
- **Heat Control** to reduce risk and avoid setbacks
- A detailed **Stats** page to track everything

---

## 🧩 Key Features

### 💼 Jobs
Run underworld operations with real-time timers and rewards:
- **Money** → fuels upgrades and market purchases  
- **Reputation** → progression and prestige  
- **Heat** → risk meter; manage it or pay the price  

### 🏛️ Imperium (Empire Hub)
A central menu with focused sub-systems:
- **Training** → level skills and unlock stronger multipliers  
- **Hideout** → upgrade levels for better income per job  
- **Crew / Bodyguards** → protective scaling + bonuses  
- **Weapons / Gear** → power progression and future loadouts  
- **Heat Control** → reduce heat and stabilize your operation  
- **Market** → spend strategically; economy-based progression  

### 📊 Stats Dashboard
A unified view of your build:
- Core stats (Money / Rep / Heat / Power)
- Combat stats (Strength & scaling)
- Economy multipliers / job efficiency
- Attributes / skill levels
- Crew / bodyguards overview
- Active bonuses & effects

### ⚡ Real-Time UI
- Timers update continuously
- Cooldowns tick live
- No refresh required

### 💾 Autosave
- Saves automatically via **localStorage**
- Persists per device/browser

---

## 🎮 Gameplay Loop

1. Run **Jobs** → earn money/rep, generate heat  
2. **Train** → increase multipliers and survivability  
3. **Upgrade** the Imperium → compound progression  
4. **Control Heat** → reduce penalties / downtime  
5. Repeat → optimize → expand → dominate
